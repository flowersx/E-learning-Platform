# Cerințe funcționale

## 1. Scopul aplicației

Platforma urmărește integrarea unui agent conversațional inteligent într-un sistem de e-learning, cu scopul personalizării experienței educaționale.

## 2. Categorii de utilizatori

### Student
- Crearea și autentificarea într-un cont
- Accesarea cursurilor și lecțiilor
- Participarea la evaluări
- Vizualizarea progresului educațional
- Interacțiunea cu agentul conversațional
- Primirea de explicații și recomandări personalizate

### Profesor
- Crearea și administrarea cursurilor
- Adăugarea materialelor educaționale
- Crearea testelor și întrebărilor
- Consultarea rezultatelor studenților

### Administrator
- Gestionarea conturilor și a rolurilor
- Administrarea generală a platformei

## 3. Componenta AI

Agentul conversațional va avea următoarele funcționalități propuse:

- Răspunsuri la întrebări educaționale
- Explicații adaptate nivelului studentului
- Utilizarea informațiilor despre progresul educațional
- Recomandarea materialelor și exercițiilor relevante
- Utilizarea conținutului cursurilor pentru formularea răspunsurilor

## 4. Evaluarea personalizării

Se propune compararea a două configurații:

1. Agent conversațional standard, fără acces la profilul studentului
2. Agent conversațional personalizat, cu acces la profilul educațional

Evaluarea va urmări corectitudinea răspunsurilor, adecvarea explicațiilor și rezultatele activităților educaționale.
