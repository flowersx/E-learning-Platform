# Jurnal de dezvoltare

## Descrierea proiectului

Dezvoltarea unei platforme E-Learning care integrează un agent conversațional inteligent pentru personalizarea procesului educațional.

## Etapa 1. Pregătirea mediului

Tehnologii selectate:
- React și TypeScript pentru frontend
- Tailwind CSS pentru interfață
- ASP.NET Core pentru backend
- SQL Server pentru baza de date
- Python, FastAPI și Ollama pentru componenta AI

## Etapa 2. Inițializarea aplicației

- Crearea repository-ului GitHub
- Configurarea proiectului React cu Vite
- Integrarea Tailwind CSS
- Configurarea React Router
- Crearea paginilor Home, Login și Dashboard
- Crearea componentei Navbar

## Etapa următoare

Definirea cerințelor funcționale și proiectarea arhitecturii platformei.
