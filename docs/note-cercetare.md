# Note de cercetare

## Tema disertației

Integrarea agenților conversaționali inteligenți în platformele de e-learning pentru personalizarea procesului educațional.

## Direcții de cercetare

1. Agenți conversaționali inteligenți în educație
2. Modele lingvistice de mari dimensiuni
3. Personalizarea procesului de învățare
4. Retrieval-Augmented Generation (RAG)
5. Evaluarea sistemelor educaționale inteligente

## Experiment propus

Compararea a două configurații:

- Agent conversațional fără personalizare
- Agent conversațional cu acces la profilul educațional al studentului

## Aspecte de evaluat

- Corectitudinea răspunsurilor
- Relevanța explicațiilor pentru nivelul studentului
- Performanța la evaluări
- Calitatea recomandărilor educaționale
