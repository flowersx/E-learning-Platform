# Decizii tehnice

## Arhitectura aplicației

Platforma va utiliza o arhitectură formată din trei componente principale:

1. Frontend React pentru interacțiunea utilizatorilor cu platforma.
2. Backend ASP.NET Core pentru gestionarea datelor și a funcționalităților educaționale.
3. Serviciu Python FastAPI pentru integrarea agentului conversațional.

## Baza de date

Microsoft SQL Server va gestiona utilizatorii, cursurile, rezultatele evaluărilor și informațiile despre progresul educațional.

## Componenta AI

Ollama va permite rularea locală a unui model lingvistic.

Logica de personalizare și utilizarea RAG vor fi definite și evaluate în etapele următoare.

## Decizii viitoare

Pentru fiecare alegere tehnică importantă vom documenta:
- Problema identificată
- Soluțiile analizate
- Soluția aleasă
- Motivele alegerii
- Rezultatele testelor
