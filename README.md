# E-Learning Platform

Platforma e-learning cu agent conversational inteligent pentru personalizarea procesului educational.

## Tehnologii

- Frontend: React, TypeScript, Tailwind CSS
- Backend: ASP.NET Core Web API
- Baza de date: SQL Server
- Serviciu AI: Python, FastAPI, Ollama

## Scopul proiectului

Dezvoltarea unei platforme educationale care integreaza un agent conversational capabil sa ofere explicatii si recomandari adaptate nivelului de cunostinte si progresului fiecarui student.

## Structura proiectului

- `frontend` - interfata web
- `backend` - API si logica aplicatiei
- `ai-service` - agentul conversational si procesarea AI
- `docs` - documentatia tehnica si academica
